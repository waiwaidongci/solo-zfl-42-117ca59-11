# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

已实现闭环：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出（作品 + 借展台账）。

借展与巡展责任台账：
- 借展单关联作品、借展方、场地、保险额和往返日期；同一作品同一时刻只能有一个进行中的借展安排。
- 出库前须依次完成状态点检、授权确认、包装交接，否则无法出库点交。
- 巡展站点按顺序接续：上一站返还点检通过后才能发往下一站，同一时刻只有一个站点负责。
- 点交记录保存经手人、时间、包装、瑕疵说明与双方确认，已登记的环节不可重复交接。
- 点交登记新增损伤即进入理赔处理；理赔未了结的作品不得再借出。
- 运输延期可登记新离站日期与原因，超期站点自动标红。
- 取消/中止按站点倒序释放后续安排并保留原因；已发生的点交与理赔记录保留、不可覆盖。
- 全部台账数据存于 localStorage，刷新后结果一致。
